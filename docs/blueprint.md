# **App Name**: SimpleStock

## Core Features:

- Intuitive Inventory Management: Easily add, view, update, and delete home inventory items across various categories (e.g., groceries, medicines), designed for maximum clarity and minimal steps.
- Automated Stock Tracking & Alerts: Update item quantities effortlessly with large, clear controls. Automatically receive low-stock alerts and expiration reminders for critical items.
- Voice-Activated Assistant: Utilize a voice-powered tool for hands-free interaction, allowing users to quickly add items or search the inventory using natural language commands, catering to ease of use for older users.
- Seamless Multilingual Support: Instantly switch all application labels and navigation text between English and Tamil, ensuring comfortable and familiar usage for all target users.
- Accessible Search and Filtering: A prominently displayed, easy-to-use search bar allows users to quickly find items by name or category, with large input fields and clear results.
- Clear Home Dashboard Overview: A minimalist home dashboard presents the two main modules — Inventory and Ledger — as clear action cards, making the app easy to use from the first screen.
- Offline Data Capability: Ensure the application functions reliably without an active internet connection, storing changes locally and synchronizing them automatically when connectivity is restored.

## Style Guidelines:

- Light mode is the default and primary color scheme, optimized for accessibility and readability for older users, complemented by a thoughtful dark mode option.
- Primary interactive color: A calming, muted green (#458131) inspired by nature and tranquility, used for key actions and highlights to guide user focus.
- Background color: A very subtle, near-white greenish hue (#F1F4F0) creates a clean, gentle backdrop that reduces visual clutter and eye strain, promoting a calm experience.
- Accent color: A vibrant yet warm yellow-green (#6AD147) provides clear contrast for secondary interactive elements, subtle notifications, and emphasis.
- Primary font: 'Inter' (sans-serif) for both headlines and body text, selected for its exceptional readability across various sizes, modern aesthetic, and robust support for both English and Tamil characters to ensure clear communication for elderly users.
- Modern, clean, and immediately recognizable line-art icons that are generously sized and feature high contrast to support quick understanding and navigation, particularly for non-technical and visually impaired users.
- All interactive elements, including buttons and tappable areas, will be significantly large and touch-friendly. Information is presented on clean, rounded cards with soft shadows and ample clean spacing to reduce visual clutter and enhance clarity. A persistent bottom tab navigation bar offers intuitive access to core functionalities.
- Subtle, smooth, and predictable transitions between screens and UI element states. Animations will enhance user feedback and create a premium, fluid experience without distracting or increasing cognitive load, aligning with accessibility needs.
